# 사진을 PDF로

아이폰 사진을 여러 장 골라 PDF 한 파일로 만드는 공개 웹앱입니다.

## 사용 방법

1. [웹앱 열기](https://azolazol.github.io/photo-to-pdf/)
2. 사진을 여러 장 선택합니다.
3. 위/아래 버튼으로 페이지 순서를 정하고 PDF 설정을 고릅니다.
4. **PDF 만들기**를 누르고, 완료 후 **PDF 열기 · 저장** 또는 **다운로드**를 누릅니다. iPhone에서는 PDF 화면의 공유 메뉴에서 **파일에 저장**을 선택하세요.

## 기능

- 여러 사진을 PDF 한 파일로 변환
- 페이지 순서 변경 및 개별 사진 삭제
- A4, Letter, 사진 크기에 맞춤
- 세로/가로 방향, 여백, 사진 맞춤 또는 페이지 채우기
- 이미지 품질 선택
- HEIC/HEIF 변환 시도

## 개인정보 처리

사진은 브라우저에서 처리되며 앱 서버로 전송되지 않습니다. PDF 생성 엔진(jsPDF 2.5.2)과 HEIC 변환 라이브러리(heic2any 0.0.4)는 저장소의 vendor 폴더에 포함되어 같은 사이트에서 로드됩니다. iCloud에만 저장된 사진은 원본이 기기에 내려온 뒤 변환될 수 있습니다.
