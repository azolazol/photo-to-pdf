# 사진을 PDF로

아이폰 사진을 여러 장 골라 PDF 한 파일로 만드는 공개 웹앱입니다.

## 사용 방법

1. [웹앱 열기](https://azolazol.github.io/photo-to-pdf/)
2. 사진을 여러 장 선택합니다.
3. 위/아래 버튼으로 페이지 순서를 정하고 PDF 설정을 고릅니다.
4. **PDF 만들기**를 눌러 저장합니다. iPhone에서는 파일 앱의 다운로드 폴더를 확인하세요.

## 기능

- 여러 사진을 PDF 한 파일로 변환
- 페이지 순서 변경 및 개별 사진 삭제
- A4, Letter, 사진 크기에 맞춤
- 세로/가로 방향, 여백, 사진 맞춤 또는 페이지 채우기
- 이미지 품질 선택
- HEIC/HEIF 변환 시도

## 개인정보 처리

사진은 브라우저에서 처리되며 앱 서버로 전송되지 않습니다. 페이지는 PDF 생성 엔진(jsPDF)과 HEIC 변환 라이브러리를 공개 CDN에서 불러옵니다. CDN 요청에는 사진 파일이 포함되지 않습니다. iCloud에만 저장된 사진은 원본이 기기에 내려온 뒤 변환될 수 있습니다.
